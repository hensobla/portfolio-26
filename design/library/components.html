Components

Components
Actions Inputs Data Display Navigation Feedback Overlays

Actions

—

Buttons, icon buttons, toggles, segmented controls, dropdowns. Starter primitives — restyle, replace, or extend in src/components/.

Inputs

—

Text, textarea, select, checkbox, radio, switch, slider, date picker, combobox. All share the same 40px height, 10px corner, and focus treatment.

Data Display

—

Cards, avatars, badges, tags, tables, skeletons. Status labels (Active / Away / Suspended) lock to a single variant project-wide.

Navigation

—

Tabs, breadcrumbs, pagination, nav menus, links. Active state is always --accent — the single signal the user follows.

Feedback

—

Alerts, toasts, progress, spinners, empty states. Brief, specific, never apologetic.

Overlays

—

Modals, popovers, tooltips, accordions. Visual shape only — focus traps and positioning logic ship as a future polish pass.
