Typography

type scale

Stepped scale from --type-display-xl down to --type-mono. Components reference the role tokens, not raw sizes.

Radii

corner discipline

Stepped, named radii. Components reference role tokens (--radius-button, --radius-card) — bare px values not allowed.

Elevation

depth strategy

Depth comes from surfaces + 1px borders, not shadows. The single allowed shadow role is --shadow-card for floating cards.

Space

spacing scale

Used for padding, gap, and margin. Off-scale values are not allowed in components.

Grid

—

A responsive 12-column grid (narrowing at smaller breakpoints) governs every module and template. Modules consume the active values — --grid-cols, --grid-gap, --grid-margin — which the media-query map in tokens.css re-points at the per-breakpoint tokens. Resize the window to see the active values change live.

Live preview at this viewport

Per-breakpoint tokens

To customize: edit --grid-cols-{xs..2xl}, --grid-gap-{xs..2xl}, or --grid-margin-{xs..2xl} in src/tokens.css. Every grid-driven module and template re-flows automatically. See system/space.md → Grid for the full reference.

Iconography

Phosphor · regular

Loomling ships with Phosphor as the default icon kit. Components reference glyphs by class name (e.g. ph ph-arrow-right). To swap kits, change the CDN link in library/tokens.html and rewrite the ph prefix in component HTML.

Motion

src/tokens.css · src/motion.css

Universal durations and easings — brand-agnostic, performance-first. Components reference var(--motion-*) and var(--ease-*) instead of hardcoded values. The reveal utilities (data-loom-reveal) layer on IntersectionObserver via src/motion.js. Reduced-motion (OS preference) collapses every duration token to 1ms automatically — see system/motion.md.

Durations

--motion-instant 100ms
--motion-fast 180ms
--motion-standard 300ms
--motion-slow 500ms
--motion-slower 800ms

Easings

--ease-linear linear
--ease-standard cubic-bezier(0.4, 0, 0.2, 1)
--ease-out cubic-bezier(0, 0, 0.2, 1)
--ease-in cubic-bezier(0.4, 0, 1, 1)
--ease-in-out cubic-bezier(0.4, 0, 0.2, 1)
--ease-spring cubic-bezier(0.34, 1.56, 0.64, 1)

Reveals

Subtle entrance animations. Apply data-loom-reveal="fade-in|rise|scale-95" to any element. src/motion.js wires IntersectionObserver automatically. The refresh icon on each card replays the animation as many times as you want.

Fade in

The most subtle entrance. Opacity 0 → 1 over --motion-standard.

data-loom-reveal="fade-in" When the entrance shouldn't draw attention.

Rise

Fades + translates from 16px below. The default choice for content blocks.

data-loom-reveal="rise" Default for hero, section, and content-block entrances.

Scale 95

Fades + scales from 95%. The "settle into place" feel for cards and tiles.

data-loom-reveal="scale-95" Cards, tiles, and grid items entering the viewport.
